CHURN PREVENTER AGENT - VOICE-OVER FOR ELEVENLABS
==================================================

HOW TO USE
----------
1. Open ElevenLabs > Text to Speech.
2. Model: Eleven v3 (it reads the [tags] in square brackets as acting directions).
3. Voice: warm, low-to-medium pitch, calm narrator. Try "Brian", "Daniel", "George"
   or "Adam" and keep whichever sounds warmest. Use the SAME voice for all 21 lines.
4. Settings: Stability = Natural (the middle option). Speed = 1.0. Leave the rest default.
5. Copy ONE block at a time (only the line under "PASTE"), generate it, and download it
   as MP3 with the exact file name shown. 21 files in total.
6. If a clip runs longer than its "Keep under" time, generate it again a little faster
   (Speed 1.05 to 1.1). Do not change the words.
7. Put all 21 MP3 files in this folder:  video/public/voice/
   Then tell Claude "voice files are in". Claude will sync them and render the final video.

Tags used below: [warm] [calm] [softly] [curious] [excited] [confident] [proud]
[reassuring] [smiles] [sighs] [pause] [short pause] [long pause].
"..." also makes a natural pause.
